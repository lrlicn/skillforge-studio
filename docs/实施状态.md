- 连接管理页已接入未配置、未连接、已连接三种真实状态，支持连接、重新授权和解除连接。
- 新增 GitHub 仓库模块，可分页读取当前授权可访问的最多 500 个仓库，并支持名称和描述搜索。

- GitHub 导入限制为 500 个文件、单文件 20 MB、总计 100 MB；截断仓库树和伪造 skill 路径会被后端拒绝。

- 新增 GitHub 工作区只读变更比较接口，可区分本地修改、远端修改、远端删除和双向冲突；比较过程不会修改数据库或远端仓库。
- 旧 GitHub 工作区缺少历史基线时使用兼容比较模式，只判断本地文件与当前远端是否一致，不伪造远端变化方向。
- 编辑工作台 Header 新增 GitHub 变更入口，比较摘要、提交基线和变更文件通过独立抽屉展示。
- 前端路由级页面已拆分至 `src/pages`；GitHub 变更能力位于 `src/features/github-changes`，编辑器类型和通用格式化工具分别位于 `src/features/editor`、`src/utils`。
- Tomcat multipart part 上限已与单次最多 500 个文件的业务规则对齐。
- Knife4j 使用纯 UI 资源包，避免 4.5.0 Starter 与 Spring Boot 3.5 所需 springdoc 版本冲突。
- 前后端构建、MySQL/Flyway V3、健康接口、OpenAPI、Knife4j 和本地导入闭环已验证。
